# mindlog-tester · 마음로그 2주 테스터 모집 페이지 (Vercel)

## 파일 구성
- `config.js` — 링크·금액·일정·문의처. **수정은 여기만** 하면 됩니다.
- `index.html` — 랜딩 원페이지
- `go/form.html`, `go/ios.html`, `go/android.html` — 버튼 클릭 집계용 중간 페이지 (0.6초 후 자동 이동)
- `vercel.json` — 깔끔한 URL + SNS 채널별 유입 주소(`/ig`, `/fb`, `/kakao`, `/blog`, `/naver`)

## 배포
1. 이 폴더를 GitHub 저장소에 올리고 Vercel에서 Import (Framework: Other, 빌드 설정 없음)
   - 또는 터미널에서 `npx vercel --prod`
2. Vercel 프로젝트 → **Analytics** 탭 → **Enable** 클릭 후 한 번 재배포

## 방문자 추적 (Vercel Web Analytics, Hobby 무료 플랜 기준)
| 보고 싶은 것 | 어디서 보나 |
|---|---|
| 방문자 수 / 페이지뷰 | Analytics → Visitors, Page Views |
| 어느 SNS에서 왔는지 | 광고별 링크를 `도메인/ig`, `도메인/fb` 처럼 다르게 걸면 **Pages**에 경로별로 집계 |
| 구글폼 버튼 클릭 수 | Pages의 `/go/form` |
| 앱 설치 버튼 클릭 수 | Pages의 `/go/ios`, `/go/android` |

- Hobby 플랜은 월 5만 이벤트, 최근 1개월 데이터까지 조회됩니다.
- "커스텀 이벤트"와 UTM 집계는 유료 플랜 기능이라, 무료 플랜에서도 보이도록 `/go/*` 페이지뷰 방식으로 클릭을 셉니다.
- 광고 차단기를 쓰는 방문자는 집계되지 않아 실제보다 조금 적게 잡힐 수 있습니다.
- 퍼널 예: `/ig` 방문 1,000 → `/go/form` 400 → 구글폼 응답 수(시트) 300

## 기관코드 노출 방지
웹페이지(소스 포함)에는 기관코드를 넣지 않았습니다. 정적 페이지는 JS로 숨겨도 소스 보기로 다 보이기 때문입니다.

구글폼 → 설정 → 프레젠테이션 → **확인 메시지**에 아래처럼 넣어주세요.

```
제출이 완료되었습니다 🎉
마음로그 기관코드: XXXXXX
앱 설치 후 [설정 > 기관코드]에 입력해 주세요.
앱 설치: https://<도메인>/#how
```

권장 설정: "응답 1회로 제한"은 구글 로그인을 강제하므로 참여율이 떨어질 수 있어 끄는 것을 권장하고, 중복은 휴대폰 번호로 사후 정리합니다. 500명 도달 시 폼 → "응답 받기" 끄기.
